# MY CINEMA

A fully interactive 3D cinema genre museum built with Three.js, WebGL and GSAP.

## Features

- Real-time 3D old-fashioned theater environment
- Detailed animated vintage projector with rotating film reels
- 13 movie genres with unique procedural 3D icons
- Persian RTL interface + cinematic English display type
- Old-film flicker, grain, burn/light-leak transitions and projector dust beam
- Synthesized projector audio via Web Audio API (opt-in only)
- Keyboard arrows, touch swipe, previous/next controls and projector click navigation
- Adaptive rendering quality, mobile optimizations and reduced-motion support
- WebGL fallback and accessible UI labels

## Deployment

The project is static and requires no build step. It is configured for GitHub Pages deployment from GitHub Actions.
